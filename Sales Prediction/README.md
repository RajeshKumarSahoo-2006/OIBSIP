# Sales Prediction Using Python

## Objective
Predict product sales based on advertising budgets spent on TV, Radio, and Newspaper.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Model
- Linear Regression

## Results
The model was trained using advertising data and achieved a good R² score for sales prediction.
